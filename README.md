# GCD Function Call in C

This program uses a function call to find the greatest common divisor
of two numbers.

## File

gcd_function.c

## Concepts Used

- Function call
- Function parameters
- Return value
- while loop

## How to Run

gcc gcd_function.c -o gcd_function
./gcd_function

## Sample Output

Enter two numbers: 24 36
GCD = 12
